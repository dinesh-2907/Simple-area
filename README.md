# Simple-area

📝 Real-Time Character Counter

A simple Real-Time Character Counter built using HTML, CSS, and JavaScript. This project allows users to type a message inside a text area while displaying the number of characters typed and the remaining characters in real time.

🚀 Features

- ✨ Clean and responsive user interface
- ⌨️ Real-time character counting
- 📊 Displays typed and remaining characters
- 🚫 Prevents users from exceeding the maximum character limit
- ⚠️ Shows a warning message when the character limit is reached
- 📱 Beginner-friendly project using only HTML, CSS, and JavaScript

🛠️ Technologies Used

- HTML5
- CSS
- JavaScript (DOM Manipulation)

📂 Project Structure

Character-Counter/
│── index.html
│── style.css
│── script.js
└── README.md

🎯 How It Works

1. Open "index.html" in your browser.
2. Type your message in the text area.
3. The character counter updates automatically as you type.
4. Once the maximum limit (200 characters) is reached, additional typing is prevented and a warning message is displayed.

📸 Output

- Real-time character counter
- Remaining character display
- Warning message when the limit is reached
- Responsive and user-friendly interface
